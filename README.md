# TG Downloader Bot

Telegram-бот на aiogram 3 + yt-dlp для скачивания видео с TikTok и Instagram.

Скачивается максимальное доступное качество без вотермарки (yt-dlp берёт видео из API платформы напрямую).

Работает и в **личке**, и в **группах/чатах** — бот сам находит ссылку в сообщении и присылает видео в тот же чат, в ответ на сообщение со ссылкой.

## Установка

1. Нужен Python 3.9+ и ffmpeg в PATH (нужен для склейки видео+аудио).
   - Windows: скачать с ffmpeg.org, добавить папку `bin` в PATH.
   - Linux: `sudo apt install ffmpeg`
   - macOS: `brew install ffmpeg`

2. Создай и активируй виртуальное окружение (рекомендуется, чтобы не зависеть от системного PATH):
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируй `.env.example` в `.env` и вписай токен бота от [@BotFather](https://t.me/BotFather):
   ```
   BOT_TOKEN=твой_токен
   ```

5. Запусти:
   ```bash
   python bot.py
   ```

## Настройки в .env

| Переменная | Что делает |
|---|---|
| `BOT_TOKEN` | Токен бота |
| `ALLOWED_USERS` | Список user_id через запятую, если хочешь ограничить доступ. Пусто = доступен всем |
| `MAX_FILE_SIZE_MB` | Максимальный размер файла, который бот попытается отправить (лимит обычного Bot API — 50 МБ) |
| `COOKIES_FILE` | (опционально) путь к `cookies.txt` — нужен для приватных/ограниченных постов Instagram |
| `API_TOKEN` | (опционально) ключ HTTP-API для приложения «Видеообои». Пусто — API выключен |
| `TIKTOK_STATE_FILE` | (опционально) путь к `tiktok_state.json` — нужен для скачивания фото-постов (слайд-шоу) TikTok, см. ниже |

## Фото-посты TikTok (слайд-шоу)

Обычные видео TikTok скачиваются без доп. настроек. А вот фото-посты
(слайд-шоу из картинок) TikTok отдаёт только залогиненным сессиям —
анонимным запросам (и даже headless-браузеру без логина) данные картинок
не приходят вообще ни при каких условиях.

Поэтому для них нужен отдельный одноразовый шаг:

1. Локально (на компьютере, где есть графический интерфейс — **не на Railway**)
   поставь Playwright и браузер:
   ```bash
   pip install playwright
   playwright install chromium
   ```
2. Запусти:
   ```bash
   python tiktok_login.py
   ```
   Откроется окно браузера — залогинься в TikTok вручную (логин/пароль,
   капча, смс-код — всё как обычно), затем нажми Enter в терминале.
   Скрипт сохранит сессию в `tiktok_state.json`.
3. Положи `tiktok_state.json` рядом с `bot.py` (там же, где `.env`) —
   локально или на Railway (например, через переменную окружения или
   просто закинув файл в репозиторий **отдельно от git**, т.к. он уже
   в `.gitignore` — файл содержит авторизованную сессию, его нельзя
   коммитить в репозиторий).

Без этого файла бот скачивает только обычные видео — фото-посты вернут
ошибку "не нашёл файл сессии".

⚠️ **Риски этого способа:**
- Используй для этого отдельный TikTok-аккаунт, не основной — есть риск
  бана при автоматизированном доступе.
- Сессия может протухнуть (TikTok разлогинит) — тогда просто запусти
  `tiktok_login.py` ещё раз и обнови файл.
- На Railway сервер стучится с дата-центрового IP — если TikTok это
  не любит, он может заблокировать сессию быстрее, чем при обычном
  использовании с домашнего IP.

## Структура проекта

```

config.py       — чтение настроек из .env
```

## Чтобы бот работал в группах

1. Добавь бота в группу обычным способом.
2. Выключи **Privacy Mode** у [@BotFather](https://t.me/BotFather): `/mybots` → выбрать бота → `Bot Settings` → `Group Privacy` → `Turn off`. Если бот уже был в группе до этого — удали его и добавь заново.

## Важно про лимит 50 МБ

Обычный Telegram Bot API не даёт ботам отправлять файлы больше 50 МБ. Для более тяжёлых видео нужен свой локальный Bot API сервер (лимит тогда вырастает до 2 ГБ).

## Дисклеймер

Скачивание видео с платформ может нарушать их условия использования, а скачивание
чужого контента без разрешения автора — нарушать авторские права. Используй бота
только для контента, на скачивание которого у тебя есть право.


## HTTP-API для приложения «Видеообои»

Если задать `API_TOKEN`, вместе с ботом запускается веб-сервер (порт из `PORT`,
Railway выставляет его сам). Android-приложение отправляет на него ссылку и
получает готовое видео — без Telegram.

```
POST /api/download
Authorization: Bearer <API_TOKEN>
{"url": "https://www.tiktok.com/..."}
```

Ответ — видеофайл (`video/mp4`) или `{"error": "..."}`. Проверка работы: `GET /health`.

На Railway: Variables → добавить `API_TOKEN`; Settings → Networking → Generate Domain.
